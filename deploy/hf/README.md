# Match Performance

Academic, non-commercial research project. Sign-in required; new accounts are approved by an administrator.

**Open the app directly at the `*.hf.space` address** (button "⋮ → Embed this Space → Direct URL"):
sign-in cookies do not work inside the embedded frame on huggingface.co.
